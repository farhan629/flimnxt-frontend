# 📺 Bigg Boss Tamil Season 9 – Live Voting App

Vote for your favorite contestant in **Bigg Boss Tamil Season 9**. Live leaderboard, confetti effects, winner highlight, and more!

🌐 **Live Site:** [https://flimnxt.shop](https://flimnxt.shop)

---

## 🚀 Features

- 🗳️ Real-time voting with Supabase
- 📊 Live leaderboard and vote bars
- 🎉 Confetti and celebration effects
- ⏳ Countdown timer to vote deadline
- 👑 Winner spotlight after voting ends
- ⚡ Instant UI updates and smooth transitions

---

## 🛠️ Tech Stack

- **Frontend:** React + Vite
- **Backend:** Supabase (PostgreSQL + Realtime)
- **Styling:** CSS3
- **Hosting:** Vercel

---

## 🚀 Getting Started (For Developers)

### 1. Clone the repository

```bash
git clone https://github.com/your-username/bigg-boss-vote-app.git
cd bigg-boss-vote-app
````

### 2. Install dependencies

```bash
npm install
```

### 3. Start local development server

```bash
npm run dev
```

Visit `http://localhost:5173` to view it in your browser.

---

## 📦 Deployment

This project is easily deployable on [Vercel](https://vercel.com):

1. Push your code to GitHub
2. Import repo on Vercel
3. Add your Supabase project keys in Vercel's Environment Variables
4. Deploy 🚀
